# GHAZAL Studio v3.0 — استوديو غزال الزجاجي الذكي

إصدار احترافي بتصميم زجاجي بني فاتح دافئ (Warm Light-Brown Glassmorphism) وحركات سلسة (Framer Motion) يضم:
- تسجيل الدخول بحسابات **Gemini** و **ChatGPT** و **Claude** مباشرة دون الحاجة لمفاتيح API (مع بقاء API كخيار إضافي).
- إدارة **Instagram** و **Facebook** و **YouTube** و **Gmail** بالذكاء الاصطناعي (رد تلقائي + جدولة ونشر).
- مساحة عمل تشاركية لإضافة أعضاء الفريق والتواصل الفوري مع مساعد AI مدمج.

## التشغيل السريع (12 ملفاً فقط)
```bash
npm install
npm run dev
```
