# GHAZAL
غزال (GHAZAL) وكيل ذكاء اصطناعي مفتوح المصدر للإشراف البرمجي. يدعم Gemini، Claude، وChatGPT عبر خزنة مشفرة محلياً. يجري فحوصات مجدولة لرصد الثغرات وتحسين الكود داخل أي مشروع عبر الواجهة أو سطر الأوامر. GHAZAL is an open-source AI oversight agent supporting Gemini, Claude, and ChatGPT via a local encrypted vault.
